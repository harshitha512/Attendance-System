#
#   Windows:
#     Install Visual Studio Build Tools + CMake
#     Or use a pre-built wheel: pip install dlib‑<version>‑cpXX‑win_amd64.whl
#     (find wheels at: https://github.com/z-mahmud22/Dlib_Windows_Python3.x)
#
# Recommended: use Python 3.10 — face-recognition 1.3.0 + numpy 1.24 are
# not yet tested against Python 3.12.
